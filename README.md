# rahul14rz.github.io

Personal portfolio of Rahul M, full stack mobile developer at Adhoc Softwares, Coimbatore.

Live at https://rahul14rz.github.io

The whole site is one file, `index.html`, with its styles and script inline. No build step: edit it and push to `main`, and GitHub Pages republishes it.

To change the content, search `index.html` for the section you want (`id="work"`, `id="projects"`, `id="skills"`, `id="recognition"`, `id="contact"`). The phone sketches in the hero are plain HTML and SVG inside `class="phone"`.
